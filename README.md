<h2>Purpose</h2>

<p>
This repository serves as a baseline for competitive programming and placement prep.
It helps juniors understand problem patterns and seniors revise important algorithms quickly.
</p>

<hr>

<h2> How to Use</h2>

<pre>
1. Start with EASY to build basics.
2. Move to MEDIUM to learn optimization.
3. Attempt HARD for advanced algorithmic thinking.
4. Solve problems first → then compare solutions.
5. Revisit before coding tests and interviews.
</pre>
